# Privacy

Any-Gender Parenthook is an offline Crusader Kings III mod and installer. The
installer does not collect, transmit, or sell personal data. It does not use
analytics, advertising, telemetry, cookies, or a hosted account service.

The installer reads only the paths needed to locate a selected CK3 `binaries`
directory, inspect compatibility hashes, and maintain its local transaction
journal, quarantine, and install-state files. Those files remain on the local
computer. A user may separately choose to download a release or visit the
project repository through their browser; those web services have their own
privacy policies.

The installer never asks for a signing password, private key, or account
credential. Release automation records public build provenance in GitHub; it
does not upload game files, save files, or local paths.
